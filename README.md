# 東京ジムマップ

**公開ページ：https://shungeekgogo.github.io/tokyo-gym-map/**

東京23区のジム・スポーツジム 6,188件を、Googleマップの評価（5点満点）・口コミ数・写真つきで地図に表示するWebアプリです。

## 起動

```bash
python -m http.server 8766 --directory tokyo-gym-map
```

ブラウザで http://localhost:8766 を開きます（`index.html` と `gyms.js` の2ファイル、ビルド不要）。

## 画面

| 操作 | 内容 |
|---|---|
| 重点エリア | 下北沢・三軒茶屋・青山/表参道・渋谷・恵比寿・中目黒・目黒・自由が丘・学芸大学・二子玉川・代々木上原・桜新町/用賀・葛西・西葛西（駅から半径1km） |
| 区 | 23区すべて／渋谷区・目黒区・世田谷区／その他の区（プルダウン） |
| 種類 | 総合スポーツクラブ・24時間/マシンジム・パーソナルジム・女性向け/小型・格闘技/ボクシング・公共/体育館・その他（レンタル等） |
| 条件 | **Zumba クラス ON/OFF**（最初は ON＝Zumbaクラスのあるジムだけ表示）、★3.5/4.0/4.5以上、チェーン、店名検索 |
| 並び順 | おすすめ順（補正スコア）／★の高い順／口コミ数順 |

## データ

- 出典：Googleマップの検索結果（2026年9月に収集）。重点3区は町名ごと・種類ごとに細かく検索し、他の20区は主要チェーンと主要駅で検索。
- 評価：Googleマップの★（5点満点）と口コミ件数。一部は件数が取得できず「Google」とだけ表示。
- 補正スコア：口コミが少ない店の点数のぶれを抑えるベイズ平均（`(★×件数 + 3.6×20) / (件数 + 20)`）。「おすすめ順」はこの値で並べます。
- 写真：Googleマップに投稿された写真を直接表示（画像はGoogleのサーバーから読み込み）。
- Zumba クラス（128件）：次の公式情報から判定。
  - セントラルスポーツ：各クラブの公式週間スケジュール（24店舗、曜日・時間つき）
  - コナミスポーツクラブ：公式プログラム検索の直近1週間の時間割（曜日・時間つき）
  - ゴールドジム：各店舗の10月スタジオスケジュールPDF、代行情報（16店舗）
  - スポーツクラブNAS：各クラブの月間レッスンスケジュールPDF（7店舗）
  - ティップネス：公式のプログラム情報（ZUMBA実施店舗）
  - その他：各ジム公式サイトのプログラム・スケジュールページの記載
  - 店舗を特定できないチェーン共通ページの記載は含めていません。実施曜日・時間は変わるので、各ジムの時間割で確認してください。
- 除外：ヨガ・ピラティス専門スタジオ、整体、ゴルフ・テニス等、23区外。
- 種類の分類は店名とGoogleのカテゴリからの自動判定のため、一部ずれることがあります。
